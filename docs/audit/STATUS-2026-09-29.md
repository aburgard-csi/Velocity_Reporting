## What the branch does (the short version)

Aaron's pipeline builds the monthly client decks for all five CSMs. James's v5 has far
deeper analysis (20 ODD sections, transaction intelligence) but no delivery loop. On
2026-09-16 the two repos read the same ODD file and disagreed on Reg E opt-in by 21 points
for one client, because each carried its own reading of the same column.

The branch ports James's analysis engine INTO Aaron's repo, behind two opt-in flags, with
every shared classification defined once so the two cannot disagree again:

1. **One reading per rule** (commits 1 and 2). `build/ars_pipeline/odd_rows.py` is now the
   single home of: which .csv inside an ODDD zip is the ODD (`odd_member`, `open_odd`),
   and the Debit? / Business? / Elig / Reg E readings (`has_debit`, `is_business`,
   `is_personal`, `is_eligible`, `business_class`, `latest_elig_col`, `rege_state`).
   Ten files that had their own copies now call these. Guard tests fail if a copy reappears.
2. **The engine** (commits 3 to 5). `build/ars_pipeline/engine/` is v5's `core/`,
   `monthly_analysis/` (minus ICS and deposits), `transaction_intelligence/`, the workbook
   and 2:1 tracker readers, and `text/` (labels, polish, headlines), as one package with
   relative imports. `run_analysis.py` runs it on the ODD the build already reads and on the
   zipped transaction files in `Inputs/Txn Files/<id>/`, writing evidence to
   `Build Artifacts/analysis/<period>/<id>/`. `engine_config.py` builds the client record
   from Aaron's ARS code tables and the workbook's Key Assumptions (no v5 clients_config).
3. **Reconciliation** (commit 6). With `RPE_ANALYSIS=1`, `build_ars_gen.py` runs the engine
   after the James block and STOPS the build if the engine's eligible base or personal take
   rate differs from what Aaron's `metrics_gen` and pack compute from the same file. The
   ODD's own `Elig` flag is the eligibility of record on both sides now.
4. **Nine transaction slides** (commit 8). With `RPE_ANALYSIS_SLIDES=1` as well, James's
   Transaction Intelligence chapter (How the money moves … How members spend) is inserted
   before "Reg E Review", each slide with a source note and every tile in the figure sidecar.
5. **Docs** (commit 9). CHANGELOG entry, CLAUDE.md file-map rows, ars-deck agent note.

Without either flag, no deck changes and Aaron's templates and layout baseline are
byte-identical to main.
